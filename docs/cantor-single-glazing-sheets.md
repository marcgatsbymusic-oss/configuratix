## Relationship Logic: Glazing Panes to Frame Profiles

Based on the Cantor database structure (`CUSTOM_SZYBY` and `CUSTOM_OKNA_PODKLADKI`), there is **no direct linkage** between an individual single glass pane (like `FL4` or `B1`) and a specific frame profile (like `IGLO 5`). 

Instead, the relationship follows an indirect hierarchy based on physical constraints:

1. **Composition**: Single glass panes are combined with spacers to create **Glazing Packages** (defined in the `CUSTOM_SZYBY` table under columns `SZYBA1`, `RAMKA1`, `SZYBA2`, etc.).
2. **Thickness Calculation**: Each glazing package has a resulting total thickness (e.g., `FL4` + `16mm spacer` + `FL4` = `24mm`).
3. **Profile Constraints**: Frame systems and profiles specify the minimum and maximum allowed glazing thickness they can support (stored in `CUSTOM_OKNA_PODKLADKI` as `GR_SZKLA_MIN` and `GR_SZKLA_MAX`). These limits are determined by the available glazing beads (`Podkladki`).

**Conclusion**: Any single glass pane can be used in any frame profile, *provided* that the final composed glazing package's total thickness falls within the supported range of the selected profile and its glazing beads.

### Standard Package Presets
While Cantor allows custom configurations, standard glazing packages (like `2-24` or `3-36`) default to specific industry-standard compositions:

- **2-Pane Packages (e.g., `2-24`)**:
  - **Glass Outside**: `T4` (Thermo 4mm)
  - **Glass Inside**: `FL4` (Float 4mm)
  - *(Glass Middle is not applicable)*

- **3-Pane Packages (e.g., `3-36`, `3-48`)**:
  - **Glass Outside**: `T4` (Thermo 4mm)
  - **Glass Middle**: `FL4` (Float 4mm)
  - **Glass Inside**: `T4` (Thermo 4mm)

These presets are automatically applied when a user selects a glazing package, but the UI allows them to freely swap out any pane.

## Glazing Synchronization Script

To ensure the web configurator stays in sync with any new single glazing panes added to the Cantor ERP database, an automated update script has been created:

- **Script Path**: `scripts/check-cantor-glazings.mjs`
- **Output Data**: `src/data/cantor_single_glazings.json`

### How it Works
The script queries the `CUSTOM_SZYBY` table and extracts all distinct glass panes currently in use across all configured glazing packages (checking `SZYBA1` through `SZYBA4`). It compares this list against the currently saved JSON file and logs any new panes that have been added to the Cantor system, saving the updated master list. This guarantees that UI dropdowns and pricing models have access to the absolute latest raw materials available.
